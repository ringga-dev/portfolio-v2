# Nyawit Portfolio

Open-source portfolio for **Nyawit** — Kotlin & Vue developer.

Built with Nuxt 4 + Vue 3 + Tailwind CSS, deployed to GitHub Pages.

Design: Awwwards UI design system (light mode, Inter font, 4px grid).

## Tech Stack

- Nuxt 4 / Vue 3
- Tailwind CSS
- GitHub Actions → GitHub Pages

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run generate
```

Output: `.output/public/`
